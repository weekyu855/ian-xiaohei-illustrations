# 提示词示例

## 直接生成一篇文章的六格配图

```text
Use $lazy-ip-article-illustrations 为下面这篇文章生成配图。
先提炼文章核心观点，给出简短六格分镜，然后直接生图，不需要等待我确认。
严格遵循 Skill：
- 默认 6 格，3 列 × 2 行；
- 所有画面必须在同一张完整画布上；
- 只进行一次图像生成；
- 固定我的慵懒男生 IP：黑色蓬松乱发、半眯眼、轻微胡茬、灰色卫衣、黑裤、白鞋；
- 白底、黑色手绘线稿、灰阶铺色、少量橙黄色点缀；
- 六格可独立裁切，人物和物件不跨格；
- 每格只讲一个视觉动作；允许 2–3 格有简短手写中文批注，其余格子不放字；禁止总标题、分格标题和序号。

<粘贴文章正文>
```

## 只规划、不生图

```text
Use $lazy-ip-article-illustrations 先不要生图。
为下面文章规划 6 格：每格写核心观点、人物动作、主要物件、视觉隐喻和可选短标签。
保证六格叙事递进且没有重复。

<粘贴文章正文>
```

## 用于知识型长文

```text
Use $lazy-ip-article-illustrations 把这篇文章做成一张六格编辑插画整版。
不要把它画成 PPT。每格用慵懒男生 IP 承担一个动作，通过原创视觉隐喻解释观点。整张图一次生成。
<粘贴文章正文>
```

## 改善角色一致性

```text
保持画面六格的主题、布局和内容不变。严格依据人物设定参考图统一主角：黑色蓬松乱发、半眯眼、轻微胡茬、灰色宽松连帽卫衣、黑裤、白色运动鞋。不要改变脸型、头身比或画风。
```
