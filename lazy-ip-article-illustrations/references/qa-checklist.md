# QA Checklist

## 画布与分格
- [ ] 只有一张完整画布。
- [ ] 恰好 6 格，默认 3 列 × 2 行。
- [ ] 六格大小与间距一致，分隔清楚。
- [ ] 每格四周有裁切安全边距。
- [ ] 人物、道具、文字不跨格、不压线。
- [ ] 没有总标题、分格标题、序号、数字徽章、图例、说明段落、页眉、水印或 Logo。

## IP 一致性
- [ ] 六格是同一个慵懒男生。
- [ ] 黑色蓬松乱发、侧分刘海保持一致。
- [ ] 半眯眼与轻微胡茬存在且风格一致。
- [ ] 灰色连帽卫衣、黑裤、白鞋不变。
- [ ] 没有未经要求添加固定配饰。
- [ ] 角色参与核心动作，不只是装饰。

## 画风
- [ ] 白底、黑色手绘线稿、灰阶铺色。
- [ ] 橙黄色只作少量强调。
- [ ] 线条、阴影和细节密度六格统一。
- [ ] 不像 PPT、矢量图、3D 或儿童卡通。
- [ ] 背景简洁，画面不拥挤。

## 内容
- [ ] 六格各有不同的叙事作用。
- [ ] 没有编造数字、事实或因果。
- [ ] 约 2–3 格有短中文手写批注，其余格子以视觉叙事为主。
- [ ] 没有总标题、分格标题、序号、数字徽章或说明段落。
- [ ] 视觉隐喻有助于理解，不歪曲原意。

## 调用次数
- [ ] 提示词准备完整后只调用一次图像生成。
- [ ] 不自动逐格生成，也不自动追加第二次生图。
